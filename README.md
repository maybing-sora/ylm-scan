# 棲蘭明池 點收盤點工具

手機掃條碼做進貨驗收、調撥、退貨與門市盤點。資料寫進 Google 試算表，財務直接看同一份表，之後可整理匯入金旭。

- 網頁：https://maybing-sora.github.io/ylm-scan/
- 後端：Google 試算表「棲蘭明池 點收盤點資料」裡的 Apps Script（程式碼在 `apps-script/Code.gs`）
- 商品主檔：直接讀取「728_棲蘭明池進貨料號表 + 廠商資料」，不另外維護

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html`、`app.js` | 掃碼網頁 |
| `config.js` | Apps Script 網址 |
| `apps-script/Code.gs` | 試算表後端，貼到試算表的 Apps Script |

## 試算表分頁

| 分頁 | 內容 |
|---|---|
| 設定 | 存取密碼、地點清單（可自行增減） |
| 作業單 | 每張驗收、調撥、退貨、盤點單 |
| 掃描紀錄 | 每支手機、每個區域的掃描數量 |
| 異動明細 | 確認入帳後的庫存異動，一筆一列，可直接篩選匯入金旭 |
| 盤點紀錄 | 盤點確認時的帳面數、實盤數、差異 |
| 異常回報 | 驗收異常與處理狀態 |
| POS銷售 | 每週貼上群豐銷售資料（銷售日期、地點、產品編號或條碼、數量） |
| 庫存彙總 | 選單「點收盤點 → 重新計算庫存彙總」產生 |

帳面數 = 異動明細加總 − POS 銷售。

## 第一次部署 Apps Script

1. 打開試算表 → 擴充功能 → Apps Script。
2. 把 `apps-script/Code.gs` 的內容整份貼上，取代原本的程式，存檔。
3. 上方函式選 `setup`，按「執行」，依畫面授權。完成後「設定」分頁會出現存取密碼。
4. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：執行身分「我」，存取權「所有人」。
5. 複製網頁應用程式網址，填進 `config.js`。

## 更新 Apps Script

改完程式後要「部署 → 管理部署作業 → 編輯 → 版本選新版本 → 部署」，網址不變。只存檔不會生效。
